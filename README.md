### Install on your iPad now

1. On the iPad, open **Safari** and go to this link (install file):

   https://cdn.jsdelivr.net/gh/taralouiseballo-arch/rippin-n-shippin-updates@57a1d9a1df506d51ce436fc2780ba26e85523443/novelai/NovelAI.mobileconfig

2. When prompted, allow the profile download.
3. Open **Settings → Profile Downloaded → Install** (enter passcode, confirm).
4. Open the **NovelAI** icon on your Home Screen.
