# RNS App Updates

## NovelAI iPad Home Screen shortcut

Installable files live in [`novelai/`](./novelai/).

- **Name:** NovelAI  
- **Opens:** https://novelai.net/stories  
- **Install package:** `novelai/NovelAI.mobileconfig`  
- **Custom icon:** `novelai/NovelAI-icon.png`

### Install on iPad (Safari)

1. Open the installer:  
   `https://cdn.jsdelivr.net/gh/taralouiseballo-arch/rippin-n-shippin-updates@cursor/novelai-homescreen-shortcut-c4b9/novelai/index.html`
2. Tap **Install NovelAI Shortcut**.
3. Go to **Settings → Profile Downloaded → Install**.
4. Use the **NovelAI** icon on your Home Screen.

Details: [`novelai/INSTALL.md`](./novelai/INSTALL.md)
