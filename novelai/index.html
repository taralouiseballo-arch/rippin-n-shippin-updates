NovelAI

Home Screen shortcut for NovelAI Stories.

Install NovelAI Shortcut Open NovelAI Stories
After you tap Install
  1. Open the Settings app.
  2. Tap Profile Downloaded near the top.
  3. Tap Install, enter your passcode, confirm.
  4. Find the NovelAI icon on your Home Screen.

The profile is unsigned (personal use). That is normal for a custom shortcut.

Use Add to Home Screen instead

Add to Home Screen (Safari)
  1. Stay on this page in Safari (not in-app browsers).
  2. Tap the Share button.
  3. Tap Add to Home Screen.
  4. Keep the name NovelAI, then tap Add.

Opening the NovelAI icon launches Stories at novelai.net.
