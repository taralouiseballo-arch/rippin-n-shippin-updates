# Install NovelAI on your iPad Home Screen

**Name:** NovelAI  
**Opens:** https://novelai.net/stories  
**Icon:** custom book + rose-gold quill

## Fastest install (recommended)

1. On your iPad, open this page in **Safari**:
   - After GitHub Pages is on: `https://taralouiseballo-arch.github.io/rippin-n-shippin-updates/novelai/`
   - Or open the raw installer from the repo’s `novelai/index.html` once hosted.
2. Tap **Install NovelAI Shortcut**.
3. Open **Settings → Profile Downloaded → Install**.
4. Enter your passcode and confirm.
5. Open the new **NovelAI** icon on your Home Screen.

## Backup method (no profile)

1. Open the same installer page in **Safari**.
2. Tap **Share → Add to Home Screen**.
3. Keep the name **NovelAI** → **Add**.

## Files in this folder

| File | Purpose |
|------|---------|
| `NovelAI.mobileconfig` | Installable Home Screen web clip (custom icon + URL) |
| `NovelAI-icon.png` | 1024×1024 custom icon |
| `icons/` | Apple touch icon sizes |
| `index.html` | Installer page |

Apple does not allow creating a signed `.shortcut` file outside the Shortcuts app. The `.mobileconfig` web clip is the installable equivalent for a Home Screen icon with a custom image.
